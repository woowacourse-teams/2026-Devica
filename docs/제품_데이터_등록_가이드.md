# 제품 데이터 등록 가이드

제품과 이미지를 등록할 때 사용하는 절차다. 이미지 제공 방식은 [ADR 0030](adr/0032-제품-이미지-저장과-제공.md)에, 일반 배포 절차는 [백엔드 배포 가이드](백엔드_배포_가이드.md)에 기록했다.

## 1. 이미지 업로드와 DB 등록

이미지는 techcourse-project-2026 버킷의 devica/dev/product-images/{prototypeId}/{sha256}.webp 키에 저장한다. 로컬 WebP 파일의 SHA-256을 계산해 키를 정하고, Content-Type을 image/webp로 지정해 업로드한다. 제품과 이미지가 실제로 대응하는지 업로드 전에 확인한다. 기존 20개 객체는 다시 업로드할 필요가 없다.

    shasum -a 256 "<로컬 WebP 파일>"
    aws s3 cp "<로컬 WebP 파일>" "s3://techcourse-project-2026/<imageKey>" --content-type image/webp

DB의 product.image_key에는 버킷 이름을 제외한 전체 객체 키를 저장한다. 애플리케이션은 환경별 이미지 주소와 이 키를 조합해 API의 imageUrl을 만든다. 로컬은 application-local.yml에 개발용 S3 주소가 명시돼 있고, 개발·운영 서버는 PRODUCT_IMAGE_BASE_URL을 반드시 설정한다. 서버 환경 변수에 devica/dev 경로까지 넣으면 경로가 중복된다.

최초 20개 제품과 CPU는 [V1.6 시드](../src/main/resources/db/migration/V1.6__seed_prototype_products.sql)로 등록한다. 새 제품을 추가하거나 기존 제품의 이미지를 교체할 때는 새 Flyway 마이그레이션으로 product.image_key와 필요한 제품 데이터를 등록·수정한다. 공유 DB에 적용된 V1.6은 수정하지 않는다.

## 2. 배포 후 확인

배포 로그에서 Flyway 적용과 애플리케이션 기동을 확인한다. 새로 등록하거나 수정한 제품 코드로 DB의 키를 조회한다.

~~~sql
SELECT p.id, p.code, p.image_key
FROM product p
WHERE p.code = '<제품 코드>';
~~~

GET /api/products/{id}의 imageUrl이 해당 환경의 이미지 주소와 조회한 image_key를 조합한 주소인지 확인한다. 이미지 URL을 인증 없이 요청해 HTTP 200과 Content-Type: image/webp가 반환되는지 확인하고, 브라우저에서 이미지가 해당 제품과 일치하는지 확인한다. 인증된 S3 HeadObject만으로는 브라우저의 공개 접근이나 이미지 내용을 확인할 수 없다.

최초 20개를 빈 제품 DB에 등록한 경우에는 CPU 10개, 제품·노트북·판매처 각 20개와 이미지 키 누락 여부를 추가로 확인한다. 이미 데이터가 있는 DB라면 전체 건수 대신 V1.6에 적힌 제품 코드를 기준으로 확인한다.

~~~sql
SELECT version, description, success
FROM flyway_schema_history
WHERE version = '1.6';

SELECT COUNT(*) FROM cpu;
SELECT COUNT(*) FROM product;
SELECT COUNT(*) FROM laptop;
SELECT COUNT(*) FROM product_offer;
SELECT COUNT(*) FROM product WHERE image_key IS NULL;
~~~

브라우저가 S3 URL로 직접 이미지를 받는 현재 구성은 해당 객체에 s3:GetObject 권한이 필요하다. 공개 읽기 범위는 제품 이미지 접두사로 한정하고, 버킷 정책의 범위는 객체 응답과 별도로 확인한다.

## 3. 실패하거나 수정할 때

마이그레이션이 실패하면 배포 로그의 실패 SQL과 원인을 확인하고, flyway_schema_history와 관련 테이블의 실제 상태를 조회한다. 개발·운영 DB에 flyway clean이나 볼륨 삭제를 사용하지 않는다. 이미 적용된 마이그레이션의 값을 고치려면 다음 버전의 마이그레이션을 추가한다.

CloudFront로 전환할 때의 경로 및 권한 설정은 [ADR 0030](adr/0032-제품-이미지-저장과-제공.md)을 따른다.
