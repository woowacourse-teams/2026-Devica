## 📜 V1 사용자 유스케이스 문서화

### 1. 서비스 정의

사용자가 제품과 사용 목적을 선택하고, 기본 또는 맞춤 사양을 확정한 뒤 조건에 맞는 제품을 탐색하는 서비스다.

### 2. 액터

| 액터     | 설명                         |
|--------|----------------------------|
| 사용자    | 사양을 확인하고 제품을 탐색하는 사람       |
| 외부 구매처 | 사용자가 제품 구매를 위해 이동하는 외부 서비스 |

### 3. 전체 흐름

```
UC-01 제품 선택
  → UC-02 사용 목적 선택
    → UC-03 기본 권장 사양 확인
      ├─ 기본 사양 사용 → UC-07 제품 검색
      └─ 맞춤 질문
          → UC-04 맞춤 사양 조정
          → UC-05 최종 사양 확인
              ↔ UC-06 최종 사양 수정
          → UC-07 제품 검색
              ├─ UC-08 검색 조건 설정
              ├─ UC-09 제품 정렬
              └─ UC-11 제품 상세 조회

각 화면 → UC-10 FAQ 조회 → 기존 화면으로 복귀
```

### 4. 유스케이스

| ID    | 이름          | 시작 조건                | 핵심 흐름                              | 종료·예외                                                   |
|-------|-------------|----------------------|------------------------------------|---------------------------------------------------------|
| UC-01 | 제품 선택       | 메인 화면 진입             | 지원 제품인 노트북을 선택한다.                  | 선택 후 UC-02로 이동한다. 미지원 제품은 선택할 수 없다.                     |
| UC-02 | 사용 목적 선택    | 제품 선택 완료             | 지원 목적인 백엔드 개발을 선택한다.               | 선택 후 UC-03으로 이동한다. 미지원 목적은 선택할 수 없다.                    |
| UC-03 | 기본 권장 사양 확인 | 제품·사용 목적 선택 완료       | OS별 기본 권장 사양과 근거를 확인한다.            | 기본 사양으로 검색하거나 맞춤 질문을 시작한다.                              |
| UC-04 | 맞춤 사양 조정    | 맞춤 질문 선택             | 현재 사양과 사용 방식에 관한 질문에 답하거나 건너뛴다.    | 답변을 바탕으로 최종 사양을 계산해 UC-05로 이동한다. 중단 후 복귀하면 진행 상태를 유지한다. |
| UC-05 | 최종 사양 확인    | 맞춤 사양 계산 완료          | OS별 최종 사양과 추천 근거를 확인한다.            | 사양을 수정하거나 해당 사양으로 제품을 검색한다.                             |
| UC-06 | 최종 사양 수정    | 최종 사양 확인 화면          | OS·CPU·RAM·SSD를 직접 수정한다.           | 유효한 조합이면 결과와 근거를 갱신한다. 유효하지 않으면 안내한다.                   |
| UC-07 | 제품 검색       | 최종 사양 확정 또는 전체 목록 진입 | 최종 사양에 맞는 제품 또는 전체 제품을 조회한다.       | 제품 목록을 표시한다. 결과가 없거나 조회에 실패하면 안내한다.                     |
| UC-08 | 검색 조건 설정    | 제품 목록 표시             | 검색어와 가격·사양·OS·브랜드 조건을 적용하거나 초기화한다. | 조건에 맞는 목록을 표시한다. 결과가 없으면 완화 가능한 조건을 안내한다.               |
| UC-09 | 제품 정렬       | 제품이 한 개 이상 존재        | 추천순·가격 낮은 순·가격 높은 순으로 정렬한다.        | 검색 조건을 유지한 채 정렬된 목록을 표시한다.                              |
| UC-10 | FAQ 조회      | FAQ 링크 선택            | 전체 FAQ 또는 현재 화면과 관련된 FAQ를 확인한다.    | 기존 화면과 진행 상태로 복귀한다. FAQ가 없으면 목록으로 안내한다.                 |
| UC-11 | 제품 상세 조회    | 제품 선택 또는 상세 주소 접근    | 제품의 주요 정보·사양·가격·추천 조건 일치 이유를 확인한다. | 외부 구매처로 이동할 수 있다. 조회할 수 없는 제품은 목록으로 안내한다.               |

### 5. 핵심 비즈니스 규칙

유스케이스 본문에 반복하지 않고 공통 규칙으로 묶는 게 좋습니다.

- V1에서 지원하는 제품은 노트북이다.
- V1에서 지원하는 사용 목적은 백엔드 개발이다.
- 추천 검색은 같은 OS이면서 최소 CPU·RAM·SSD를 만족하는 제품만 대상으로 한다.
- 검색 조건은 함께 적용하고 사용자 동의 없이 자동으로 해제하지 않는다.
- FAQ나 제품 상세에서 돌아오면 기존 진행·검색 상태를 유지한다.
- 구매 링크는 외부 구매처로 연결한다.
