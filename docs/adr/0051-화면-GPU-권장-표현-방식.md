# 51. 노트북의 GPU 는 `gpu` 테이블의 벤치마크 점수로, 화면 색 영역은 노트북 행의 등급으로 저장한다

- 상태: Accepted
- 날짜: 2026-11-03

## 상황 (조건)

- 디자인 사용 목적의 제품 추천에 화면 색 영역과 GPU 를 권장 항목으로 더하기로 했다(#322).
- 제품 데이터에는 화면 색 영역과 GPU 값이 없었다.
- 권장 사양은 그대로 맞춤 제품 목록의 검색 조건이 된다.
- CPU 는 `cpu` 테이블에 벤치마크 점수를 둔다. 맞춤 제품 목록은 노트북의 CPU 점수가 권장 등급의 최소 점수 이상인지 비교한다([0024](0024-권장-CPU-표현-방식.md)).
- GPU 벤치마크 점수는 이후에 자동 갱신 파이프라인을 구축할 계획이다.
- Mac 은 GPU 가 칩에 들어 있다. 칩 등급에 따라 GPU 코어 수가 다르다.
- Blender 공식 권장 사양은 GPU 를 "VRAM 8GB"로만 정한다. 특정 GPU 모델은 지정하지 않는다.
- 화면 색 영역의 제조사 표기는 sRGB·NTSC·DCI-P3 비율, "컬러 볼륨" 등으로 제각각이다.
- 웹 화면의 기준 색 공간은 sRGB 이다. 영상은 DCI-P3 같은 더 넓은 색 공간을 쓴다.

## 고려한 대안

**1. GPU 를 "내장 / 외장 / VRAM 8GB 이상 외장" 같은 등급으로 노트북 행에 저장한다**

- 공식 권장 사양이 "VRAM 8GB"처럼 적혀 있어 그 표현 그대로 등급을 나눌 수 있다.
- 노트북에는 등급만 있고 GPU 점수를 담을 곳이 없다. 나중에 점수를 받아 와도 쓸 수 없다.
- 등급 기준을 바꾸면(예: "VRAM 12GB 이상" 등급 추가) 노트북마다 등급을 다시 매겨야 한다.
- Mac 은 GPU 가 칩 안에 있어 언제나 "내장" 등급이 된다. 외장 GPU 보다 빠른 M5 Pro 칩도 가장 낮은 등급이 된다.

**2. 화면 색 영역을 "DCI-P3 100%" 같은 수치로 노트북 행에 저장한다**

- 권장 기준이 바뀌어도(예: DCI-P3 90% → 95%) 저장한 값은 그대로 두면 된다.
- 제조사마다 기준 색 공간이 sRGB·NTSC·DCI-P3 로 달라 같은 숫자로 비교하려면 서로 바꾸는 규칙이 필요하다.
- "컬러 볼륨"처럼 색 영역 비율이 아닌 표기도 있어 숫자로 옮길 수 없는 제품이 있다.

## 선택: GPU 는 `gpu` 테이블의 벤치마크 점수로, 화면 색 영역은 노트북 행의 등급으로 저장한다

**GPU**

- CPU 와 같은 방식이다. GPU 마다 `gpu` 테이블에 한 행을 두고 벤치마크 점수를 적는다. 노트북은 자기 GPU 행을 가리킨다(`gpu_id`).
- 권장 GPU 는 기본·중급·고성능 세 등급(`GpuTier`)이다. 등급마다 최소 점수가 있다.
  - 중급: 보급 외장 GPU 인 RTX 4050 Laptop 이 들어가는 점수부터
  - 고성능: Blender 권장 VRAM 8GB 급인 RTX 4060 Laptop 이 들어가는 점수부터
- 맞춤 제품 목록은 노트북의 GPU 점수가 권장 등급의 최소 점수 이상인 제품만 보여 준다.

**화면 색 영역**

- 노트북 행에 STANDARD(sRGB 수준)·WIDE(DCI-P3 처럼 넓은 색 영역) 중 하나를 적는다(`ColorGamut`).
- 맞춤 제품 목록은 권장 등급 이상인 제품만 보여 준다.

**두 항목 공통**

- 가장 낮은 등급(기본 GPU, STANDARD)을 권하면 목록 조건을 걸지 않는다. 모든 노트북이 갖추기 때문이다.
- 정의서에 GPU·색 영역 구간이 없는 사용 목적은 이 두 항목을 권하지 않는다.

**근거**

1. 점수가 `gpu` 행 한 곳에만 있어 점수를 갱신할 때 노트북 데이터는 건드리지 않아도 된다.
2. 외장 여부가 아니라 점수로 나누므로, Mac 칩 GPU 도 성능만큼 등급을 받는다.
3. 기준이 되는 색 공간이 웹은 sRGB, 영상은 DCI-P3 두 가지뿐이라 등급 두 개로 충분하다. 제품을 등록할 때 한 번만 나누면 되므로 표기를 바꾸는 규칙도 필요 없다.

## 감수하는 것

1. **VRAM 용량은 따로 보지 않는다**

   Blender 는 "VRAM 8GB"를 권하지만 목록은 GPU 점수만 본다. 그래서 점수는 고성능 등급을 넘지만 VRAM 이 8GB 보다 적은 GPU 도 목록에 나올 수 있다.

   대응: 고성능 등급의 기준을 VRAM 8GB 인 RTX 4060 Laptop 으로 잡아 이런 경우를 줄였다. GPU 마다 VRAM(`gpu.vram_gb`)도 적어 두어 필요하면 VRAM 조건을 더할 수 있다.

2. **벤치마크를 바꾸면 등급 기준도 다시 정해야 한다**

   등급의 최소 점수(`GpuTier.minScore`)는 지금 쓰는 벤치마크의 점수 단위로 정했다. 다른 벤치마크로 바꾸면 점수 단위가 달라져 최소 점수도 새로 정해야 한다. CPU 도 같다([0024](0024-권장-CPU-표현-방식.md) 감수 1).

   대응: 벤치마크를 바꿀 때 최소 점수도 함께 바꾼다.

3. **처음 넣은 GPU 점수 중 일부는 믿기 어렵다**

   M5 Pro 20코어 GPU 는 측정 결과가 1건, RTX 4050 Laptop 은 2건뿐이다. Radeon 840M 은 결과가 없어 비슷한 GPU 를 보고 추정했다. 등급 기준 근처에 있는 GPU 는 점수가 조금만 달라도 등급이 바뀐다.

   대응: 마이그레이션 주석에 점수의 출처와 측정 건수를 남긴다. 자동 갱신 파이프라인을 만들 때 실제 값으로 바꾼다.

4. **Mac 은 권장 CPU 보다 높은 칩만 목록에 나올 수 있다**

   Mac 은 GPU 를 따로 고를 수 없고 칩에 따라 정해진다. 그래서 영상 FHD 처럼 CPU 는 M 칩을 권해도, 중급 GPU 를 갖춘 칩이 M5 Pro 부터라 목록에는 M5 Pro 만 나온다.

   대응: 결과 화면에 GPU 권장도 함께 보여 준다. 사용자는 목록이 왜 M5 Pro 로 좁아졌는지 알 수 있다.

5. **색 영역 등급을 바꾸면 제품을 다시 나눠야 한다**

   노트북마다 STANDARD·WIDE 를 적어 두므로, 예를 들어 등급을 셋으로 늘리면 모든 노트북의 등급을 다시 매겨야 한다.

   대응: 마이그레이션 주석에 노트북마다 등급을 정한 근거(제조사 표기)를 남겨 다시 나눌 때 참고한다.

6. **공식 수치가 없는 색 영역은 비공식 자료로 채웠다**

   제조사가 색 영역을 밝히지 않은 노트북이 있다. 값을 비워 두면 색 영역 조건이 걸린 목록에서 그 노트북이 빠지므로, 판매처 사양표나 리뷰 자료로 채웠다. 실제와 다를 수 있다.

   대응: 마이그레이션 주석에 출처를 남긴다. 공식 수치를 확인하면 다음 마이그레이션으로 고친다.
