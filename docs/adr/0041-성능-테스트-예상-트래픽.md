# 41. 성능 테스트의 예상 트래픽을 홍보 직후 피크로 정한다

- 상태: Accepted
- 날짜: 2026-10-14

## 상황 (조건)

- 실사용 데이터가 거의 없다. 홍보한 날에도 유입은 하루 수십 명이었다.
- 지금까지의 홍보 중 네이버 카페 맥쓰사(회원 약 81만 명)에 올린 글의 반응이 가장 좋았다. 320회 조회되었고, 그중 56명이 들어왔다.
- 카페 글은 게시 직후에 조회가 몰린다.
- 테스트는 API마다 RPS를 정해 부하를 건다([0040](0040-성능-테스트-측정-범위.md)). 그래서 기준 트래픽은 API별 RPS로 바꿀 수 있어야 한다.

## 고려한 대안

**1. 시장 규모로 추정한 평상시 트래픽**

- 공개 통계에서 출발해 근거를 대기 쉽다. 점유율을 100%로 두면 실제보다 작게 잡을 걱정이 없는 상한이 된다.
- 상한으로 잡아도 상품 목록 API가 초당 0.1건이 안 된다(아래 추정 과정). 어떤 구현도 통과해서 테스트가 위험을 드러내지 못한다.

## 선택: 홍보가 잘 됐을 때 10분간 약 260명이 들어온다

| 항목 | 기준 |
| --- | --- |
| 예상 트래픽 | 홍보 직후 10분간 약 260명 유입 (조회 1,500회 × 클릭률 17.5%) |
| API별 RPS | 260 × 방문당 해당 API 호출 수 ÷ 600 |

방문당 호출 수와 10분 안에서 유입이 몰리는 모양은 API마다 화면 흐름이 달라 각 테스트의 README에 둔다.

**근거**

1. 평상시 트래픽은 시장 전체를 가져와도 성능 위험이 되지 않는다. 위험이 생기는 때는 홍보글이 노출된 직후의 짧은 시간이다.
2. 클릭률 17.5%는 반응이 가장 좋았던 맥쓰사 홍보에서 실측한 값이다. 그래서 추정에 남는 가정이 조회 수와 몰리는 시간 두 가지로 줄어든다.
3. 조회 수 1,500회는 최근 7일 인기글의 최댓값이다. 맥쓰사 홍보글(320회)이 이미 다른 앱 소개 글(191·212회)보다 잘 된 편이라, 화제가 된 글이 받는 상한을 기준으로 삼았다.
4. 몰리는 시간 10분은 카페 글이 게시 직후에 조회가 몰리는 점을 보수적으로 잡은 가정이다.

## 감수하는 것

1. **조회 수와 몰리는 시간은 실측이 아니다**

   조회 수 1,500회와 10분은 추정한 값이다. 실제로 사람이 더 많이, 더 짧은 시간에 몰리면 테스트를 통과해도 서버가 버티지 못할 수 있다.

   대응: 다음 홍보 때 조회 수와 시간대별 유입을 재서 값을 바꾼다.

2. **가장 잘 된 홍보 한 번을 기준으로 한다**

   클릭률은 맥쓰사 홍보 한 번에서 잰 값이다. 다른 채널은 클릭률이 다를 수 있고, 여러 채널에 동시에 올리는 경우는 반영하지 않는다.

## 참고: 추정 과정

**평상시 트래픽의 상한** (대안 1)

| 단계            | 값          | 근거                                      |
|---------------|------------|-----------------------------------------|
| ① 국내 개발자      | 약 40만 명    | SW 산업 종사자 38.75만 명 (2018 소프트웨어 산업 실태조사) |
| ② 개발자 지망생     | 약 10만 명    | 가정 (공개 통계를 찾지 못함)                       |
| ③ 백엔드 비율      | 약 23.5%    | 2025 상반기 개발자 입사 지원 중 서버/백엔드 비중          |
| ④ 대상 인구       | 약 12만 명    | (① + ②) × ③                             |
| ⑤ 연간 노트북 구매자  | 약 2.7만 명   | 컴퓨터 평균 교체 주기 4.5년 → 연 22%               |
| ⑥ 월간 구매자      | 약 2,200명   | ⑤ ÷ 12                                  |
| ⑦ 구매자당 방문 수   | 3회         | 가정 (고민 기간 중 여러 번 방문)                    |
| ⑧ 하루 방문       | 약 220회     | ⑥ × ⑦ ÷ 30                              |
| ⑨ 피크 1시간 집중도  | 하루의 10%    | 가정                                      |
| ⑩ 방문당 목록 요청   | 15건        | 가정 (상품 목록 테스트의 세션 구성: 진입 5번 × 3페이지)     |
| 목록 API 피크 RPS | 약 0.09 RPS | ⑧ × ⑨ × ⑩ ÷ 3,600                       |

**홍보 피크** (선택)

| 항목           | 값      | 근거                                                                      |
|--------------|--------|-------------------------------------------------------------------------|
| 클릭률          | 17.5%  | 반응이 가장 좋았던 맥쓰사 홍보글. 조회 320회 중 56명이 들어왔다                                 |
| 잘 됐을 때의 조회 수 | 1,500회 | 2026-10-11 기준 최근 7일 인기글 20개 중 최댓값. 중간값은 약 190회, 노트북 구매 고민 글은 349~481회였다 |
| 피크 유입        | 약 260명 | 1,500 × 17.5%                                                           |
| 몰리는 시간       | 10분    | 가정 (게시 직후 조회가 몰리는 편이라 보수적으로 잡았다)                                        |
