# 2. 프레임워크로 Spring Boot 4.1.0을 사용한다

- 상태: Accepted
- 날짜: 2026-08-17

## 상황 (조건)

- 언어를 Java로 결정했으므로, 후보는 Java 진영의 웹 프레임워크로 좁혀진다.
- 팀원 전원이 Spring Boot 프로젝트를 처음부터 세팅하고 배포까지 해본 경험이 있다.
- MVP까지 약 1개월로, 프레임워크 학습이나 설정 시행착오에 쓸 여유가 없다.

## 고려한 대안

실질적으로 검토한 대안은 없다.

Java 진영에 Quarkus, Micronaut 등이 있으나, 이들의 강점인 빠른 기동과 낮은 메모리 사용량은 서버리스나 대규모 트래픽 환경에서 유효하다. MVP 검증 단계의 우리 조건에서는 이점이 체감되지 않는 반면, 팀에 경험이 없어 학습 비용만 발생한다. 따라서 후보로 올리지 않았다.

## 선택: Spring Boot 4.1.0

**근거**

1. 팀원 전원이 Spring Boot 프로젝트를 처음부터 세팅하고 배포까지 해본 경험이 있다. 이번 프로젝트에서 수행할 작업을 그대로 해본 셈이므로, 설정 단계의 시행착오 없이 기능 개발에 바로 착수할 수 있다.
2. 1개월 안에 검증을 마쳐야 하므로 문제 해결에 시간을 쓸 여유가 없다. Spring Boot는 국내외 자료와 레퍼런스가 풍부해, 막혔을 때 해결책을 빠르게 찾을 수 있다.

**버전: 4.1.0**

3.x 계열은 3.5를 마지막으로 2026년 6월 OSS 지원이 모두 종료되어, 보안 패치를 받을 수 없다. 4.0은 2026년 12월에 종료되므로, MVP 이후 운영을 이어간다면 곧 업그레이드 작업이 필요해진다.

4.1은 2027년 7월까지 지원되므로, 프로젝트 기간과 이후 운영까지 버전 관리에 시간을 쓰지 않아도 된다.

## 감수하는 것

1. **비교 검토를 거치지 않은 결정**

   조건이 달라지면(트래픽 증가, 서버 비용 압박 등) 재검토가 필요하다.

2. **팀이 경험한 3.x와 다른 메이저 버전**

   Boot 4는 Spring Framework 7 기반이라 레퍼런스가 아직 적다. 초기 세팅 단계에서는 문제가 없었으나, 기능 개발이 진행되면서 3.x와의 차이가 드러날 가능성은 남아 있다.
