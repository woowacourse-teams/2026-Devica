# 52. 지운 질문·선택지 코드는 서버가 지금 코드로 바꿔 읽는다

- 상태: Accepted
- 날짜: 2026-11-05

## 상황 (조건)

- 결과 링크에는 사용자가 고른 답이 `질문 코드=선택지 코드` 로 담기고, 제품 추천 의견 이슈에도 이 링크가 남는다.
- 제품 추천 개선 루프가 질문과 선택지를 지우거나 코드를 바꾸게 된다(#344). 의견 이슈의 링크가 열리지 않으면 그 의견을 개선 근거로 쓸 수 없어, 지운 코드가 담긴 링크도 계속 열어 주기로 했다.
- 설문 내용은 사용 목적마다 서버의 정의서 파일에만 있고, 화면은 서버에서 설문을 받아 그린다([0046](0046-추천-콘텐츠-위치.md)).
- 루프의 Feedback Analyzer 는 화면을 거치지 않고, 의견 이슈의 결과 링크로 서버 API 를 직접 불러 그 사용자의 결과를 다시 계산한다.

## 고려한 대안

**1. 화면이 지운 코드를 지금 코드로 바꿔 서버에 보낸다**

- 서버는 지금 설문의 코드만 받으므로 결과 API 를 고칠 필요가 없다.
- 바꿔 읽는 방법을 화면 코드에 적으면 설문을 고칠 때마다 화면도 함께 고쳐야 한다. 설문을 서버에서만 관리할 수 없게 된다. 목록을 서버에서 받아 와도 그 목록을 해석하는 코드는 화면에 따로 있어야 한다.
- 서버 API 를 직접 부르는 Feedback Analyzer 는 이렇게 해도 옛 링크의 결과를 재현하지 못한다.

## 선택: 정의서 옆의 지운 코드 목록 파일(`<사용 목적>.retired.yml`)에 바꿔 읽는 방법을 적고, 결과 API 가 계산하기 전에 바꿔 읽는다

지운 질문·선택지 코드마다 지금 코드로 바꿔 읽거나(`to`), 그 답을 버리는(`drop`) 줄을 남긴다. 줄마다 지운 날짜(`retiredAt`)를 적고, 목록 파일의 보관 기간(`keepMonths`)이 지난 줄은 서버가 무시한다. 규칙이 바뀌어 옛 답이 더는 맞지 않는 질문은 `dropInvalid` 로 그 답을 버린다. 바꿔 읽거나 버린 답이 있으면(노출 조건 때문에 버린 경우 포함) 결과 응답에 `answersOutdated` 를 담고, 화면은 결과 위에 안내와 "다시 답하기" 버튼을 둔다. 줄이 없는 코드는 지금처럼 거부하고 화면은 "질문이 바뀌어 다시 답해야 해요." 를 보인다.

**근거**

1. 바꿔 읽는 방법을 설문과 같은 곳(서버의 사용 목적별 파일)에서 관리한다. 설문을 고치는 PR 에 목록 변경이 함께 들어가 리뷰어가 변경과 그 영향을 한곳에서 확인한다.
2. 화면과 Feedback Analyzer 가 같은 결과 API 를 거치므로 사용자가 연 옛 링크의 결과와 루프가 재현한 결과가 같다.

## 감수하는 것

1. **바꿔 읽은 결과는 처음 본 결과와 다를 수 있다**

   지운 답은 빠지고, 합친 선택지는 남는 선택지의 규칙으로 계산된다. 규칙도 그 사이에 바뀌었을 수 있다.

   대응: 결과 위에 "질문이 바뀌어 지금 질문에 맞춰 다시 읽었어요. 처음 본 결과와 다를 수 있어요." 안내와 "다시 답하기" 버튼을 둔다.

2. **쪼갠 선택지는 옛 답을 살리지 못한다**

   선택지 하나를 둘로 나누면 옛 답이 어느 쪽에 해당하는지 알 수 없어 그 답을 버린다.

   대응: 버린 답이 있으면 1 과 같은 안내를 보인다.

3. **같은 변환 규칙을 서버와 개선 루프 스크립트가 각각 구현한다**

   개선 루프는 서버를 부르지 않고 정의서로 영향 범위를 계산하므로(#344), 변환 규칙이 Java 와 Python 두 곳에 있다.

   대응: 두 구현을 같은 변환 사례표(`src/test/resources/recommendation/retired-cases.json`)로 테스트한다.

4. **보관 기간이 지난 링크는 다시 열리지 않는다**

   지운 코드 목록이 계속 쌓이지 않도록 줄마다 보관 기간(6개월)을 둔다. 기간이 지난 코드가 담긴 링크는 줄이 없는 코드처럼 거부된다.

   대응: 화면은 "질문이 바뀌어 다시 답해야 해요." 를 보이고 다시 답하게 한다. 기간이 지난 줄은 다음에 설문을 지우는 PR 에서 함께 지워, 정리만 하는 커밋을 따로 만들지 않는다.
