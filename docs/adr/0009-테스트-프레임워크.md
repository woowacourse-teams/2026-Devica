# 9. 테스트에 JUnit 5와 AssertJ를 사용한다

- 상태: Accepted
- 날짜: 2026-08-17

## 상황 (조건)

- Spring Boot 프로젝트이며, 팀원 전원이 이전 미션에서 JUnit 5와 AssertJ를 사용해왔다.
- 테스트는 동작 검증뿐 아니라 코드의 의도를 설명하는 역할도 하므로 가독성이 중요하다.

## 고려한 대안

실질적으로 검토한 대안은 없다.

JUnit 5는 Spring Boot가 기본으로 제공하는 테스트 프레임워크이고, 검증 라이브러리로는 JUnit 내장 `Assertions`를 별도 의존성 없이 쓸 수도 있다. 다만 팀이 이전 미션에서 AssertJ를 계속 사용해왔고 가독성 이점도 명확해, 다른 선택지를 검토하지 않았다.

## 선택: JUnit 5 + AssertJ

**근거**

1. JUnit 5는 Spring Boot의 기본 테스트 프레임워크로, 별도 설정 없이 사용할 수 있다.
2. AssertJ는 메서드 체이닝 방식으로 검증문을 작성하므로, 무엇을 검증하는지가 문장처럼 드러난다. 테스트가 설명서 역할을 하려면 이 가독성이 중요하다.
3. 팀원 전원이 이전 미션에서 두 도구를 사용해왔으므로, 학습 없이 바로 작성할 수 있다.

## 감수하는 것

없다. AssertJ는 의존성 하나가 늘어날 뿐이고, JUnit 내장 `Assertions`와 함께 쓸 수도 있어 포기하는 것이 없다.
