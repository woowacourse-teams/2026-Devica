## 작성 방법

[Template.md](Template.md)를 복사해 `NNNN-주제.md` 형식으로 만든다. 번호는 마지막 문서 다음 번호를 이어서 쓴다.

### 상태

| 상태 | 의미 |
|---|---|
| Proposed | 논의 중이며 아직 적용하지 않음 |
| Accepted | 결정되어 적용 중 |
| Deprecated | 더 이상 사용하지 않음 |
| Superseded | 다른 결정으로 대체됨. 대체한 문서 번호를 함께 적는다 |

### 결정을 번복할 때

기존 문서를 고치지 않는다. 새 문서를 만들어 결정을 기록하고, 기존 문서의 상태를 `Superseded by NNNN`으로 바꾼다. 판단이 바뀐 과정 자체가 기록으로 남아야 하기 때문이다.

이때 **무엇이 달라져서 판단이 바뀌었는지**를 새 문서의 상황에 적는다. 조건이 그대로인데 결론만 바뀌었다면, 처음의 판단이 조건에 근거하지 않았다는 뜻이다.

## 작성 원칙

- **상황**: 우리 팀의 구체적 조건을 쓴다. 어느 팀에나 해당되는 일반론은 조건이 아니다.
- **고려한 대안**: 조건이 달랐다면 선택했을 수 있는 실질적 후보만 남긴다. 장단점은 일반적인 특성 그대로 쓰고, 우리 상황에 비춘 판단은 아래에서 한다. 검토한 대안이 없었다면, 없었던 이유를 적는다.
- **선택**: 근거는 앞의 상황에 실제로 대응해야 한다. **상황을 지워도 성립하는 문장은 근거가 아니다.**
- **감수하는 것**: 대안 비교의 요약이 아니라, 선택 이후 팀이 실제로 관리하게 될 목록이다. 일반적인 단점이라도 우리 상황에서 비용이 되지 않으면 제외한다. 감수할 것이 없다면 없다고 쓰고, 그렇게 판단한 이유를 적는다.
