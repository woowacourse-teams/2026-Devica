# 35. 로그 수집기로 Grafana Alloy를 사용한다

- 상태: Accepted
- 날짜: 2026-09-30

## 상황 (조건)

- 로그 저장소는 Grafana Cloud(관리형 Loki)다([ADR 0034](0034-로그-저장소.md)).
- 수집기는 애플리케이션 서버(AWS t4g.small, 메모리 2GiB, ARM64)에서 함께 실행된다.
- 스프린트 3부터 부하 테스트를 진행한다.

## 고려한 대안

실질적으로 검토한 대안은 없다. Grafana Cloud는 Alloy를 기본 수집기로 안내하며 설치 명령과 설정을 함께 제공한다.

## 선택: Grafana Alloy

**근거**

1. Grafana Cloud가 설치 명령과 설정을 제공해, 별도 조사 없이 바로 연동할 수 있다.
2. 메트릭과 트레이스도 수집할 수 있어, 서버에 에이전트 하나로 통일할 수 있다.

## 감수하는 것

1. **애플리케이션과 서버 자원을 나눠 쓴다**

   메모리 2GiB 중 일부를 수집기가 사용한다.

   대응: 부하 테스트 때 Alloy의 자원 사용량을 함께 관찰하고, 필요하면 컨테이너 메모리를 제한한다.
