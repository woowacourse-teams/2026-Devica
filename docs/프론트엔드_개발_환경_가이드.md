# 프론트엔드 개발 환경 가이드

**`frontend/`를 고칠 때 보는 문서다.** 백엔드 환경은 [백엔드 개발 환경 가이드](백엔드_개발_환경_가이드.md)에서 다룬다.

---

## 1. 최초 세팅

스택은 React 19.3 · Vite 8.3 · TypeScript 7.0 이다 ([ADR 0025](adr/0025-프론트엔드-구현-방식-변경.md)). Node 22 이상이 필요하다.

```bash
cd frontend
npm install
```

`npm install`은 의존성과 함께 **Git 훅도 설치한다** (`prepare` 스크립트가 husky 를 실행한다). 훅이 없으면 커밋할 때 린트·포맷이 적용되지 않고, 리뷰 기록 검사도 push 가 아니라 PR 의 CI 단계에서야 걸린다.

린트·포맷은 Biome 이 맡는다. 에디터에 Biome 플러그인(VS Code, IntelliJ 모두 있다)을 설치하면 저장할 때 같은 규칙으로 포맷된다.

## 2. 커밋과 push 에서 일어나는 일

| 시점 | 하는 일 | 막히면 |
|---|---|---|
| 커밋 (pre-commit) | 스테이징된 `frontend/` 파일에 Biome 자동 수정(안전한 것만)과 타입 검사 | 남은 에러를 고치고 다시 커밋한다 |
| push (pre-push) | 리뷰 기록(`.review/`)이 push 하는 코드와 맞는지 검사 | 에이전트에서 `review` Skill 을 실행하고 기록을 커밋한다 |
| PR (CI) | push 와 같은 검사 | push 와 같다 |

작업 흐름 전체는 [`AGENTS.md`](../AGENTS.md)에, 리뷰 규칙은 [`docs/review-rules`](review-rules/README.md)에 있다.
