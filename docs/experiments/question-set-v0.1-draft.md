## 1. 질문 구성 제안

- [ ] 조건부 Q8을 건너뛸 때 진행률은 실제 노출 질문 수를 기준으로 계산한다.

## 2. 질문·선택지·효과 승인표

아래 효과는 원문을 옮긴 것이며, `후보`라고 적힌 항목은 아직 실제 결과값이 정해지지 않았다.

### Q1. 어떤 노트북을 생각하고 계신가요?

| 선택지 | 원문 효과 |
| --- | --- |
| 맥 | 기준값 유지. 하향 재확인에 증설 불가 안내 |
| 윈도우 | 메모리 기준값을 32GB로 상향. 저장 공간 증설 가능성 안내 |
| 아직 안 정했다 | 맥 기준으로 값을 잡음 |

### Q2. 주로 다루는 언어는 무엇인가요?

| 선택지 | 원문 효과 |
| --- | --- |
| Java, Kotlin, C# 등 | 메모리 상향 후보, CPU 상향, Q8 노출 |
| Node.js, TypeScript | 저장 공간 상향 후보 |
| Python | 조정 없음 |
| Go, Rust 등 | 조정 없음 |
| PHP, Ruby 등 | 조정 없음 |
| 아직 정하지 않았다 | 기준값 유지, 하향 근거로 사용하지 않음 |

결정 필요: 중복 선택 허용 여부와 `조정 없음` 선택지를 묶을지 여부가 원문에서 미정이다.

### Q3. 어떤 IDE를 쓰나요?

| 선택지 | 원문 효과 |
| --- | --- |
| IntelliJ, PyCharm 등 JetBrains 제품 | 메모리 상향 후보 |
| VS Code | 조정 없음 |
| Vim, Neovim 등 터미널 에디터 | 조정 없음 |
| 여러 개를 함께 쓴다 | 메모리 상향 후보 |
| 아직 모르겠다 | 기준값 유지 |

### Q3-1. AI 코딩 도구를 쓰나요?

| 선택지 | 원문 효과 |
| --- | --- |
| Cursor 같은 AI 전용 에디터를 쓴다 | 메모리 상향 후보 |
| 기존 IDE에 확장으로 붙여 쓴다 | 조정 없음 |
| 안 쓴다 | 조정 없음 |

### Q4. 개발 환경을 어떻게 띄우나요?

| 선택지 | 원문 효과 |
| --- | --- |
| 서비스를 서너 개씩 함께 띄운다 | 메모리 32GB 이상 경로, 저장 공간 상향 후보 |
| 도커로 여러 개를 한 번에 띄운다 | 메모리 상향, 저장 공간 상향 후보 |
| 도커로 한두 개 띄운다 | 메모리 기준값 유지, 저장 공간 상향 후보 |
| 로컬에 직접 설치해서 쓴다 | 기준값 유지 |
| 원격 서버에 접속해서 쓴다 | 하향 조건 하나, 단독 적용 금지 |
| 아직 다뤄본 적이 없다 | 기준값 유지, 하향 근거로 사용하지 않음 |

### Q5. 지금 쓰는 컴퓨터의 저장 공간은 얼마인가요?

| 선택지 | 원문 효과 |
| --- | --- |
| 256GB 이하 (약 230GB 이하로 표시) | Q7과 교차 판정 |
| 512GB (약 460~480GB로 표시) | Q7과 교차 판정 |
| 1TB 이상 (약 930GB 이상으로 표시) | Q7과 교차 판정 |
| 모르겠다 | Q7 단독 판정 |

| --- | --- |

### Q7. 용량이 부족해서 뭔가를 지우거나 옮긴 적이 있나요?

| 선택지 | 원문 효과 |

| 한두 번 있다 | 기준값 유지 |
| 없다 | Q5가 512GB 이상일 때만 하향 조건 하나 |

### Q8. 빌드나 테스트가 끝나기를 기다리는 게 답답했나요?

| 선택지 | 원문 효과 |
| --- | --- |

| 참을 만했다 / 신경 안 쓰였다 | 조정 없음 |

### Q8-1. 개발할 때 노트북이 뜨거워지거나 팬이 크게 도나요?

| 선택지 | 원문 효과 |
| --- | --- |

| 가끔 / 별로 없다 | 조정 없음 |

### Q9. 이 노트북을 얼마나 쓸 생각인가요?

| 선택지 | 원문 효과 |
| --- | --- |
| 2년 정도 (곧 바꿀 수 있다) | 하향 조건 하나 |
| 3~4년 | 기준값 유지 |
| 5년 이상 / 오래 쓰고 싶다 | 메모리·저장 공간 상향 후보 |

## 3. 기본값과 판정 규칙

### 원문에 적힌 값

| 항목 | 원문 값 |
| --- | --- |
| 메모리 | 24GB |
| 저장 공간 | 512GB |
| CPU | 메모리에서 역산 |
| OS | 미지정 시 Mac |
| Windows 메모리 기준 | 32GB |

### 원문에 적힌 판정 원칙

- 상향 조건은 하나만 충족해도 적용한다.
- 하향 조건은 둘 이상 충족해야 적용한다.
- 정보 부족은 하향 근거로 사용하지 않는다.
- CPU는 질문으로 세밀하게 조정하지 않고 메모리에서 역산한다.

### 구현 전 추가 결정이 필요한 값

- [ ] 메모리 상향 결과: `24GB → ?`
- [ ] 메모리 하향 결과: `24GB → ?`
- [ ] 저장 공간 상향 결과: `512GB → ?`
- [ ] 저장 공간 하향 결과: `512GB → ?`
- [ ] Mac CPU 기본·상향 등급의 정확한 표시값
- [ ] Windows CPU 기본·상향 등급의 정확한 표시값
- [ ] 여러 상향 조건이 겹칠 때 한 단계만 올릴지 누적할지
- [ ] 상향 조건과 하향 조건이 동시에 충족될 때 우선순위
- [ ] 사용자가 OS를 정하지 않았을 때 정말 Mac으로 확정할지, `미정`으로 유지할지

## 4. 결과 설명과 제품 연결

승인해야 할 결과 항목은 `PROCESSOR`, `MEMORY`, `STORAGE`, `OS` 네 개다.

- [ ] 각 사양 옆에 어떤 답변 때문에 값이 변경되었는지 표시한다.
- [ ] 사용자가 결과 화면에서 선택 가능한 정확한 값 목록을 정한다.
- [ ] OS 변경 시 PROCESSOR를 자동 변경하는 매핑을 정한다.
- [ ] 기존 Mac 제품 목록의 어떤 필드를 사양과 비교할지 정한다.
- [ ] `이상`, `정확히 일치`, 등급 비교 중 제품 필터의 비교 방식을 정한다.
