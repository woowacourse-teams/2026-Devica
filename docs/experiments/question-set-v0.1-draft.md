# question-set-v0.1 승인 완료

> 상태: **질문·선택지·추천 정책·제품 목록 승인 완료**
> 이 문서는 승인 완료된 질문·추천 규칙과 제품 연결 계약의 전체 기록이다. 파일명은 기존 링크 보존을 위해 `-draft.md`를 유지한다.

## 1. 전체 화면과 질문 순서

초기 화면에는 Mac과 Windows의 기본 권장 사양을 함께 표시한다. `선택 사양 조정`을 누르면 번호가 없는 **현재 노트북 사양 입력 화면**을 먼저 표시한다. 다음 화면부터 Q1을 시작한다. Q3과 Q3-1은 한 화면의 두 선택 영역으로 표시한다.

| 표시 단계 | 질문 ID | 화면 또는 질문 | 노출 조건 |
| --- | --- | --- | --- |
| 1 | 사전 입력 | 현재 사용하는 노트북 사양 | 전원, 모든 항목 선택 입력 |
| 2 | Q1 | 어떤 노트북을 생각하고 계신가요? | 전원 |
| 3 | Q2 | 주로 다루는 언어는 무엇인가요? | 전원 |
| 4 | Q3 + Q3-1 | 어떤 IDE를 쓰나요? / AI 코딩 도구를 쓰나요? | 전원, 한 화면의 두 선택 영역 |
| 5 | Q4 | 개발 환경을 어떻게 띄우나요? | 전원 |
| 6 | Q5 | 프로그램을 여러 개 켜두면 멈추거나 껐다 켜야 했나요? | 전원 |
| 7 | Q6 | 용량이 부족해서 뭔가를 지우거나 옮긴 적이 있나요? | 전원 |
| 8 | Q7 | 빌드나 테스트가 끝나기를 기다리는 게 답답했나요? | Q2에서 Java·Kotlin·C# 묶음을 선택한 경우 |
| 9 | Q7-1 | 개발할 때 노트북이 뜨거워지거나 팬이 크게 도나요? | 전원 |
| 10 | Q8 | 이 노트북을 얼마나 쓸 생각인가요? | 전원 |

### 진행 규칙

- Java·Kotlin·C# 묶음을 선택하면 사전 입력 화면을 포함해 총 10단계다.
- Java·Kotlin·C# 묶음을 선택하지 않으면 Q7을 건너뛰며 총 9단계다.
- 진행률은 사용자에게 실제로 노출하는 단계 수를 기준으로 계산한다.
- Q2는 복수 선택이고, Q3과 Q3-1은 각각 답해야 다음 단계로 진행할 수 있다.
- 사전 입력 화면은 아무 항목도 입력하지 않아도 다음 단계로 진행할 수 있다.

## 2. 현재 노트북 사양 사전 입력 화면

사용자가 `선택 사양 조정`을 누른 직후 Q1 이전에 표시한다.

| 입력 항목 | 입력 여부 | 처리 규칙 |
| --- | --- | --- |
| OS | 선택 | 입력하지 않으면 `미입력`으로 유지한다. 추정하거나 기본값으로 간주하지 않는다. 새로운 수치 조정 규칙을 적용하지 않는다. |
| CPU | 선택 | 입력하지 않으면 `미입력`으로 유지한다. Q7 또는 Q7-1에서 CPU 상향이 발생할 때만 아래 CPU 연동 규칙에 사용한다. |
| RAM(GB) | 선택 | 입력하지 않으면 `미입력`으로 유지한다. 입력값으로 새로운 수치 조정 규칙을 만들지 않는다. |
| SSD 용량(GB) | 선택 | 입력하지 않으면 `미입력`으로 유지한다. Q6 저장 공간 판정에만 사용한다. |

### 공통 입력 원칙

- 네 항목은 모두 선택 입력이다.
- 입력하지 않은 값을 추정하거나 권장 사양의 기본값으로 취급하지 않는다.
- OS와 RAM 사전 입력값에는 새로운 상향·하향 조건을 적용하지 않는다.
- CPU 사전 입력값은 Q7의 `자주 답답했다` 또는 Q7-1의 `자주 그렇다`를 선택해 CPU 상향이 발생할 때만 사용한다.
- SSD 사전 입력값은 Q6의 저장 공간 상향·하향 판정에만 사용한다.

### SSD 용량 구간 판정

- SSD는 세 구간 중 하나를 고르는 선택 입력이며 사용자가 숫자를 직접 적지 않는다.
- `256GB 이하`는 `512GB 상당 미만`, `256GB 초과 1TB 미만`과 `1TB 이상`은 `512GB 상당 이상`으로 판정한다.
- 구간으로 묻기 때문에 OS에 약 460~480GB로 표시되는 512GB 모델도 사용자가 가운데 구간을 골라 `512GB 상당 이상`이 된다.
- SSD를 입력하지 않으면 용량 구간을 추정하지 않는다. 상향 조건과 하향 조건 모두에 사용하지 않는다.

### 승인된 사전 입력 선택지

- OS: `Mac`, `Windows`
- CPU: OS를 선택한 뒤 활성화한다.
  - Mac: `M 칩 → M Pro 칩 → M Max 칩`
  - Windows: `Core Ultra 5 235U / Ryzen AI 5 340급 → Core Ultra 7 258V / Ryzen AI 7 445급 → Core Ultra 7 255H / Ryzen 7 H 260급 → Core Ultra 9 275HX / Ryzen 9 8940HX급`
- RAM: `8GB 이하`, `16GB`, `24GB`, `32GB`, `64GB 이상`
- SSD: `256GB 이하`, `256GB 초과 1TB 미만`, `1TB 이상`
- 현재 CPU는 같은 OS 권장안에만 반영한다.

## 3. 질문·선택지·효과 승인표

`상향 후보`, `상향`, `하향 조건`은 4절의 승인된 수치와 우선순위에 따라 계산한다.

### Q1. 어떤 노트북을 생각하고 계신가요?

| 선택지 | 효과 |
| --- | --- |
| 맥 | 기준값 유지. 하향 재확인에 증설 불가 안내 |
| 윈도우 | 메모리 기준값을 32GB로 상향. 저장 공간 증설 가능성 안내 |
| 아직 안 정했다 | Mac과 Windows 권장안을 모두 계산하고 결과 화면에 두 카드로 표시 |

### Q2. 주로 다루는 언어는 무엇인가요?

Q2는 복수 선택이다. `아직 정하지 않았다`를 선택하면 다른 선택은 모두 해제되고, 다른 언어를 선택하면 `아직 정하지 않았다`가 해제된다.

| 선택지 | 효과 |
| --- | --- |
| Java, Kotlin, C# 등 | 메모리 상향 후보, CPU 상향, Q7 노출 |
| Node.js, TypeScript | 저장 공간 상향 후보 |
| Python, Go, PHP 등 | 조정 없음 |
| 아직 정하지 않았다 | 기준값 유지. 하향 근거로 사용하지 않음 |

여러 언어를 선택하면 각 선택지에서 발생한 조정 조건을 함께 평가한다.

### Q3. 어떤 IDE를 쓰나요?

| 선택지 | 효과 |
| --- | --- |
| IntelliJ, PyCharm 등 JetBrains 제품 | 메모리 상향 후보 |
| VS Code, Vim, Neovim 등 | 조정 없음 |
| 여러 개를 동시에 함께 쓴다 | 메모리 상향 후보 |
| 아직 모르겠다 | 기준값 유지 |

### Q3-1. AI 코딩 도구를 쓰나요?

Q3과 같은 화면에서 별도의 선택 영역으로 표시한다.

| 선택지 | 효과 |
| --- | --- |
| Cursor 같은 AI 전용 에디터를 쓴다 | 메모리 상향 후보 |
| 기존 IDE에 확장으로 붙여 쓴다 | 조정 없음 |
| 안 쓴다 | 조정 없음 |

### Q4. 개발 환경을 어떻게 띄우나요?

| 선택지 | 효과 |
| --- | --- |
| 로컬에 직접 설치해서 여러 개 띄운다 | 메모리 32GB 이상 경로, 저장 공간 상향 후보 |
| 로컬에 직접 설치해서 한두 개 띄운다 | 기준값 유지 |
| 도커로 여러 개를 한 번에 띄운다 | 메모리 상향, 저장 공간 상향 후보 |
| 도커로 한두 개 띄운다 | 메모리 기준값 유지, 저장 공간 상향 후보 |
| 원격 서버에 접속해서 쓴다 | 하향 조건 하나. 단독 적용 금지 |
| 아직 다뤄본 적이 없다 | 기준값 유지. 하향 근거로 사용하지 않음 |

### Q5. 프로그램을 여러 개 켜두면 멈추거나 껐다 켜야 했나요?

| 선택지 | 효과 |
| --- | --- |
| 자주 그렇다 | 메모리 +16GB 적용 |
| 가끔 느려진다 | `자주 그렇다`의 50%인 메모리 +8GB 적용 |
| 괜찮다 | 조정 없음 |

승인된 실제 조정값은 `자주 그렇다` +16GB, `가끔 느려진다` +8GB다. 40GB처럼 실제 단일 제품 구성과 다른 값도 최소 요구량으로 유지하고 제품 검색에서는 그 이상의 구성을 찾는다.

### Q6. 용량이 부족해서 뭔가를 지우거나 옮긴 적이 있나요?

Q6의 답변은 SSD 사전 입력 여부와 관계없이 받는다. 다만 SSD 용량을 입력하지 않았다면 저장 공간 수치를 변경하지 않는다.

| 사전 입력 SSD | 선택지 | 효과 |
| --- | --- | --- |
| 512GB 상당 이상 | 자주 있다 | 저장 공간 상향 |
| 512GB 상당 이상 | 한두 번 있다 | 기준값 유지 |
| 512GB 상당 이상 | 없다 | 저장 공간 하향 조건 하나 |
| 512GB 상당 미만 | 자주 있다 | 저장 공간 수치 조정 없음 |
| 512GB 상당 미만 | 한두 번 있다 | 기준값 유지 |
| 512GB 상당 미만 | 없다 | 저장 공간 수치 조정 없음 |
| 미입력 | 자주 있다 | 답변만 기록하고 저장 공간 수치 조정 없음 |
| 미입력 | 한두 번 있다 | 답변만 기록하고 기준값 유지 |
| 미입력 | 없다 | 답변만 기록하고 저장 공간 수치 조정 없음 |

### Q7. 빌드나 테스트가 끝나기를 기다리는 게 답답했나요?

노출 조건: Q2에서 `Java, Kotlin, C# 등`을 선택한 경우.

| 선택지 | 효과 |
| --- | --- |
| 자주 답답했다 | CPU 등급 상향. Mac은 Pro 등급 안내 유지 |
| 참을 만했다 / 신경 안 쓰였다 | 조정 없음 |

#### CPU 사전 입력 연동 (Q7·Q7-1 공통)

- CPU를 입력했고 Q7 `자주 답답했다` 또는 Q7-1 `자주 그렇다`를 선택하면 사전 입력 CPU를 한 단계 상향한다.
- 사전 입력 CPU의 한 단계 상향 결과와 기본 권장 CPU 등급을 비교한다.
- 두 값 중 더 높은 등급을 최종 CPU로 선택한다.
- 따라서 최종 CPU가 기본 권장 CPU 등급보다 낮아질 수 없다.
- CPU를 입력하지 않았으면 기존 CPU 상향 규칙을 그대로 적용한다.
- Mac의 Pro 등급 안내를 유지한다.

판정식:

```text
CPU 입력 있음 + Q7 또는 Q7-1 상향 답변
  최종 CPU = max(사전 입력 CPU의 한 단계 상향, 기본 권장 CPU)

CPU 입력 없음 + Q7 또는 Q7-1 상향 답변
  최종 CPU = 기존 CPU 상향 규칙 결과
```

### Q7-1. 개발할 때 노트북이 뜨거워지거나 팬이 크게 도나요?

| 선택지 | 효과 |
| --- | --- |
| 자주 그렇다 | Windows는 H·HX 계열 권장. Mac은 등급 상향 후보 |
| 가끔 / 별로 없다 | 조정 없음 |

`자주 그렇다`의 CPU 계산에는 Q7과 동일한 사전 입력 연동 규칙을 적용한다.

### Q8. 이 노트북을 얼마나 쓸 생각인가요?

| 선택지 | 효과 |
| --- | --- |
| 2년 정도 (곧 바꿀 수 있다) | 하향 조건 하나 |
| 3~4년 | 기준값 유지 |
| 5년 이상 / 오래 쓰고 싶다 | 메모리·저장 공간 상향 후보 |

## 4. 기본값과 종합 판정 규칙

### OS별 기본 권장 사양

| OS | CPU | 메모리 | 저장 공간 |
| --- | --- | --- | --- |
| Mac | M 칩 | 24GB | 512GB |
| Windows | Core Ultra 7 258V / Ryzen AI 7 445급 | 32GB | 512GB |

사전 입력 화면에서 OS·CPU·RAM·SSD를 입력하지 않아도 두 권장 사양을 별도로 계산한다. 단, 미입력 값을 현재 사양으로 추정하지 않는다.

### 메모리 판정표

| 구분 | 조건 |
| --- | --- |
| 일반 상향 +16GB | Q2 Java 계열, Q3 JetBrains 또는 여러 개, Q3-1 AI 전용 에디터, Q4 로컬 여러 개 또는 도커 여러 개, Q5 `자주 그렇다` |
| 절반 상향 +8GB | 다른 일반 상향 조건 없이 Q5 `가끔 느려진다` |
| 하향 -8GB | Q4 원격 서버와 Q8 2년 정도를 모두 충족 |
| 보강 근거 | Q8 5년 이상. 단독으로 상향하지 않음 |
| 조정 없음 | 사전 입력 RAM 자체, 정보 부족 답변, Q5 `괜찮다` |

### 저장 공간 판정표

| 구분 | 조건 |
| --- | --- |
| 상향 1TB | Q2 Node.js·TypeScript, Q4 로컬 여러 개 또는 도커 사용, 사전 입력 SSD 512GB 상당 이상 + Q6 `자주 있다` |
| 하향 조건 | Q4 원격 서버, 사전 입력 SSD 512GB 상당 이상 + Q6 `없다`, Q8 2년 정도 |
| 하향 256GB | 하향 조건을 둘 이상 충족 |
| 보강 근거 | Q8 5년 이상. 단독으로 상향하지 않음 |
| 수치 조정 없음 | 사전 입력 SSD 512GB 상당 미만인 상태의 Q6 `자주 있다`·`없다`, SSD 미입력 상태의 모든 Q6 답변 |

### CPU 판정표

| 구분 | 조건 또는 처리 |
| --- | --- |
| 등급 순서 | Mac `M 칩 → M Pro 칩 → M Max 칩`, Windows `Core Ultra 5 235U / Ryzen AI 5 340급 → Core Ultra 7 258V / Ryzen AI 7 445급 → Core Ultra 7 255H / Ryzen 7 H 260급 → Core Ultra 9 275HX / Ryzen 9 8940HX급` |
| 기본 등급 | Mac `M 칩`, Windows `Core Ultra 7 258V / Ryzen AI 7 445급` |
| Q2 Java 계열 | 현재 권장 CPU 한 단계 상향 |
| Q7·Q7-1 상향 | 같은 OS의 사전 CPU가 있으면 `max(사전 CPU+1단계, 현재 권장 CPU)` |
| 사전 입력 없음·다른 OS | 현재 권장 CPU 한 단계 상향 |
| 최상위 등급 | 추가 상향 없이 최상위 유지 |
| OS 안내 | Q7 Mac은 Pro 등급 안내, Q7-1 Windows는 H·HX 계열 권장 |

### OS 판정표

| 구분 | 처리 |
| --- | --- |
| 권장 OS | Q1 답변을 사용 |
| Q1 미정 | Mac과 Windows 권장안을 모두 유지 |
| 사전 입력 OS | 기록만 하고 새로운 상향·하향 수치 규칙을 적용하지 않음 |

### 공통 판정 원칙

- 여러 상향 조건이 겹쳐도 가장 강한 한 번만 적용한다. CPU의 Q2·Q7·Q7-1 순차 상향은 예외다.
- 정보 부족은 하향 근거로 사용하지 않는다.
- 하향 조건은 둘 이상 충족해야 실제 하향한다.
- 상향과 하향이 동시에 성립하면 해당 OS의 기준값으로 상쇄한다.
- Q5 `가끔 느려진다`는 `자주 그렇다`의 50%만 반영한다.
- Q6은 SSD를 입력하지 않으면 답변을 기록하되 저장 공간 수치를 변경하지 않는다.
- Q7·Q7-1의 사전 입력 CPU 연동 결과는 현재 권장 CPU보다 낮아질 수 없다.

## 5. 결과 설명과 제품 연결

결과 항목은 `PROCESSOR`, `MEMORY`, `STORAGE`, `OS` 네 개다.

- 각 사양 옆에 어떤 답변 때문에 값이 변경되었는지 표시한다.
- OS 수정값은 `Mac`, `Windows`, `둘 다`다. OS를 바꾸면 같은 답변으로 계산해 둔 해당 OS 권장안으로 전환한다.
- CPU는 해당 OS의 전체 등급, RAM은 `16·24·32·40·48·64GB`, SSD는 `256GB·512GB·1TB` 중 수정한다.
- 하향 수정은 경고 후 사용자가 확인하면 반영하고 원래 권장 이유는 유지한다.
- 제품 검색은 OS 정확히 일치, CPU 등급 이상, RAM·SSD 용량 이상으로 비교하고 **쿠팡 일반 판매가 낮은 순**으로 정렬한다.
- 승인된 제품 세트 `product-set-2026-08-14-v0.1`의 16개 행을 정적 제품 데이터로 공개한다.
- 사용자에게 표시하는 출처·가격·구매 링크는 모두 쿠팡으로 통일한다.
- 쿠폰·카드·와우 회원 조건을 제외한 일반 판매가만 표시한다.
- 구매 링크는 `itemId`와 `vendorItemId`를 포함한 정확한 상품 옵션 URL이며 제휴·검색 추적 파라미터를 넣지 않는다.
- 제조사 공식 검증 링크는 제품 승인 문서에만 기록하고 결과 카드에는 노출하지 않는다.
- 가격은 확인일 기준 정적 스냅샷이며 런타임 크롤링이나 쿠팡 API를 사용하지 않는다.
