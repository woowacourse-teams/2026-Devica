## 현재 구현 범위

현재는 저장된 URL과 `external_item_id`의 일치 여부를 검증하는 [기준 ID 준비](쿠팡_판매상품_ID_준비.md) 단계다.
위 사양은 기존 초기 데이터의 참고값이며, 매일 전체 사양을 검증하거나 신규 제품을 수집하는 기능은 구현하지 않는다.
다음 단계에서는 응답의 `vendorItemId`를 기준 ID와 대조하고 동일 옵션의 가격을 갱신한다.
조회되지 않았다는 이유만으로 품절 또는 다른 제품이라고 확정하지 않는다.

## 가격 기준 — 일반 판매가로 결정

2026-10-19에 `price`를 **저장된 URL이 가리키는 정확한 옵션 1개를 누구나 별도 자격이나 쿠폰 발급 없이 구매할 때의 일반 판매가**로 결정했다. 현재 상세 화면의 **일반 판매가** 표시와 같은 뜻으로 사용한다. 누구에게나 즉시 적용되는 공개 할인은 반영하고, 특정 카드·회원 등급·별도 발급 쿠폰 조건부 가격은 제외한다. 배송비는 이 상품 가격과 구분하며, 확인하지 못한 배송비를 0원으로 가정하지 않는다.

예를 들어 같은 옵션에 `정가 240만 원`, `일반 판매가 220만 원`, `카드 결제 시 210만 원`이 보이면 이 기준의 `price`는 220만 원이다. 페이지에서 일반 판매가를 명확히 찾지 못하면 임의로 정가나 카드 가격을 대입하지 않는다.

수집기의 가격 선택 규칙, 백엔드의 입력 검증, 화면의 가격 문구를 이 기준에 맞춘다. 배송비까지 합친 최종 결제 금액을 비교하려면 데이터 구조와 화면 문구를 추가로 설계해야 한다.
