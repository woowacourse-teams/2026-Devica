## 검토 범위

- 이슈 #174: 시안에 맞춘 홈 화면, 서비스 소개, 카테고리 선택 진입점, 최근 질문 4개와 게시판 진입점, 헤더와 푸터.
- `docs/review-rules/async-request.md`, `docs/review-rules/state-model.md`를 각각 별도 리뷰어가 검토했다.
- 홈은 기존 취소 가능한 게시판 조회 훅을 재사용하고, 첫 페이지 4개를 요청한다. 기존 게시판의 기본 조회 크기 20개는 유지한다.
- 시안의 게시글 제목과 댓글 수, 시안 안내 문구는 서비스 데이터로 하드코딩하지 않는다.

## 검증

- 변경한 프론트엔드 8개 파일에 Biome 검사·포맷 적용, TypeScript 검사와 Vite 프로덕션 빌드 통과.
- Chrome에서 API 계약에 맞춘 테스트 응답으로 브라우저 검증했다. 운영 서버에 글이나 댓글을 등록하지 않았다.
- 홈의 요청 범위와 최신 질문 4개 표시, 질문 상세 진입, 뒤로 가기, 질문·댓글 등록, 홈 재방문 시 최신 목록 갱신을 확인했다.
- 홈의 로딩, 빈 목록, 조회 실패, 재시도, 응답 대기 중 다른 화면 이동을 확인했다.
- 사양 찾기 → 카테고리 → 사용 목적 → 기본 사양 → 질문 답변 → 결과 → 맞춤 제품 목록의 이동을 확인했다.
- 제품 목록의 정렬·검색, 제품 상세 진입, 목록 복귀 시 검색 조건 보존, FAQ 펼침과 이전 화면 복귀를 확인했다.
- 헤더 메뉴 순서·색상·활성 상태, 푸터 이메일 링크, 키보드 Enter 게시판 진입을 확인했다.
- 1536/1280/1024/768/600/390/320px 화면과 긴 질문 제목에서 가로 넘침이 없음을 확인했다.
- 1536×1024 화면을 시안과 비교하고, 390px 화면도 캡처해 시각적으로 확인했다.
- 브라우저 JavaScript 오류 없음. 실제 백엔드를 연결한 통합 검증은 수행하지 않았다.
